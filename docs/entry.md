### When entry
- Entry will take each 5 min candle completed
- If momemterm is bearish then bear entry
- If momenterm is bulish then bull entry
- If no momenterm then no entry
- If momenterm but EMA9 or EMA13 is negative ATR distance base on entry time, then no entry
- When EMA9 test it will consider EMA9 EMA21 and EMA200 (Never apply both ema same time)
- When EMA13 test it will consider EMA13 EMA48 and EMA200 (Never apply both ema same time)
- Never entry if candle touch ema48/ema21 or cross ema48/ema21
